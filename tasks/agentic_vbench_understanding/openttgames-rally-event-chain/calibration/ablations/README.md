# Ablations

Degraded-input runs. Each must score at or below 0.15 against the frozen verifier.
Numbers here must come from real runs, never from constructed submissions.

`single-frame`, `no-media`, `frame-dump` - produced by `../runpack/run_ablation.sh`.

`video-only` / `audio-only` do not apply: this task declares audio as not required.
